# Portfolio

My personal portfolio website. Made with React + Vite, framer-motion for animations and lenis for smooth scrolling.

Live: deployed on vercel

## Projects on it

- **Shoplex** - e-commerce app (MERN) - [code](https://github.com/Guava99/shoplex)
- **Intelligence Platform** - interview and coding practice app with Gemini - [code](https://github.com/Guava99/IntelligencePlatform)

## Run it locally

```
npm install
npm run dev
```

Build with `npm run build`, it goes to `dist/`.

## Notes

- All the text (about, skills, projects etc.) is in `src/data/portfolio.js`, so to change anything just edit that file.
- Contact form doesn't have a backend yet, it just opens your mail app with the message filled in.
- The glass distortion effect only works in chrome/edge. Firefox and safari show normal blur.
